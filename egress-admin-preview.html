▶一 · 优选入口 prefs客户端连哪个 CF 边缘 · 全局一套

这是什么：客户端（手机/电脑上的代理软件）优先连到哪些 CF 边缘 IP。与出口是两个正交维度。怎么填：每行一条 IP:PORT，端口省略默认 443；也可粘贴优选 API 返回的整片结果。

➕ 手动 / 批量添加

💡 检测为本地模拟，真实延迟需后端探针；此处仅用于排序筛选。

▶二 · 出口节点 egressWorker 出站目标 · SOCKS5 / 反代域名

这是什么：Worker 把流量送到哪里（决定你的出口国家/地区）。两种类型： ① SOCKS5（推荐）：真正的代理服务器，值填 账号:密码@地址:端口（无密码则 地址:端口），例如你的 smart-vpngate。 ② 反代域名：VLESS 节点地址指向某个域名/CDN，值填 域名:端口。 每个出口可启用/停用，并设一个默认出口（未指定 ?egress= 时使用）。

➕ 手动添加

名称建议用 地区-城市，会显示在订阅节点名里。

🛰 智能发现（smart-vpngate）

调用 VPS 管理接口，自动把 proxy_ok=true 端口识别为出口

需 VPS 开放 :8787 且带 CORS
